# XuTurn

A fully local-first file toolbox for Android & iOS — images, PDFs, archives, QR codes and a private vault. All processing happens on your device; no account, no cloud, no tracking.

[![Platform](https://img.shields.io/badge/platform-Android%20%7C%20iOS-blue)](#download)
[![Network](https://img.shields.io/badge/network-offline%20first-green)](#privacy)

## Features

- **Image tools** — compress, convert formats, batch resize, images to PDF, EXIF-aware editing
- **PDF tools** — merge, split, page reordering/rotation, watermark, AES-256 encryption & decryption
- **Archive tools** — create and extract ZIP archives
- **QR tools** — generate and scan QR codes
- **Private vault** — PIN + gesture unlock, sandbox-isolated encrypted storage for sensitive files
- **LAN transfer** — share files to any browser on the same Wi-Fi (PC included), no cable needed
- **Device migration** — move vault data between phones end-to-end re-encrypted

# XuTurn

一款完全本地优先的文件工具箱，支持 Android 与 iOS——图片、PDF、压缩包、二维码，以及私密保险箱。所有处理均在设备本地完成：无账号、无云端、无追踪。

## 功能特性

- **图片工具** —— 压缩、格式转换、批量改尺寸、图片转 PDF、EXIF 自适应的图片编辑
- **PDF 工具** —— 合并、拆分、页面重排/旋转、水印、AES-256 加密与解密
- **压缩工具** —— 创建与解压 ZIP 压缩包
- **二维码工具** —— 生成与扫描二维码
- **私密保险箱** —— PIN + 手势解锁，沙盒隔离的加密存储，保管敏感文件
- **局域网互传** —— 同一 Wi-Fi 下向任意浏览器（含电脑）分享文件，无需数据线
- **多设备迁移** —— 保险箱数据在手机之间端到端重加密迁移
