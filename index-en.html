Features

Core features

Seven tool families covering ~90% of your daily file tasks — all on-device.

Im

Images

Edit (crop, rotate, resize, opacity, color), smart compress, collage & long-image stitch, split.

P

PDF

Images to PDF, PDF to images, merge, split, compress, page management, watermark, password.

Z

Archives

Create ZIP archives and extract common formats — no network or third-party app needed.

Q

QR codes

Generate styled codes (color, error correction) and scan & recognize.

+

Vault

AES-256 encrypted storage unlocked with PIN + gesture; private files bound to your device.

⇄

LAN transfer

Send files to your computer over local Wi-Fi — direct, no external server involved.

F

Files

Browse and share everything inside the sandbox, export or delete in one tap.

Privacy

Privacy first — by default, not by choice

No cloud, no account. Your files stay in your hands from start to finish.

✓

No cloud

All processing happens in the on-device sandbox — no upload, collection or analysis.

✓

End-to-end local

LAN transfer connects only over your own Wi-Fi; transfers never touch an external server.

✓

Encrypted vault

Vault files use AES-256; only a password verification value is stored — a lost password can't be recovered.

✓

Minimal permissions

Camera is used only for photo / QR capture; no location, contacts, microphone or SMS.
