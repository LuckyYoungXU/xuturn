XuTurn

檔案操作純本機，電腦只需瀏覽器

一款純本機的檔案工具箱，所有處理都在裝置內完成，資料不上雲、不收集、不分析。

Features

核心功能

七大類工具，涵蓋你日常 90% 的檔案處理需求，全部在本機執行。

圖

圖片處理

編輯（裁剪、旋轉、調整尺寸、透明度、色彩）、智慧壓縮、模板拼圖與長圖拼接、圖片拆分。

P

PDF 工具

圖片轉 PDF、PDF 轉圖片、合併、拆分、壓縮、頁面管理、浮水印、密碼保護。

Z

解壓縮

建立 ZIP 壓縮檔，解壓常見壓縮格式，無須連網或第三方應用。

碼

QR Code

自訂顏色與糾錯等級的 QR Code 產生，支援掃碼辨識與匯出。

鎖

檔案保險箱

AES-256 加密儲存，PIN 碼 + 手勢雙重解鎖，私密檔案與裝置綁定。

傳

區域網互傳

與電腦在同一 Wi-Fi 下點對點互傳檔案，不經過任何外部伺服器。

文

檔案管理

集中查看、分享沙盒內的所有檔案與處理成果，一鍵匯出或刪除。

Screens

Privacy

隱私優先，是預設而非選項

我們不依賴雲端，也不依賴帳號。你的檔案從頭到尾都在你自己手中。

✓

資料不上雲

所有處理在裝置本機沙盒完成，不上傳、不收集、不分析任何使用者資料。

✓

端到端本機

區域網互傳僅在本地 Wi-Fi 內直連，收發檔案不經過任何外部伺服器。

✓

加密保險箱

保險箱檔案 AES-256 加密，僅本機保存密碼校驗值，遺忘無法找回。

✓

最小權限

僅在使用拍照 / 掃碼時呼叫相機；不申請定位、通訊錄、麥克風等敏感權限。
